# Weather Dash

A small, fast weather dashboard written in plain HTML, CSS and JavaScript. It has no build step and needs no API key.

**Live demo:** https://cfdgasman.github.io/weather-dash/

- Search for any city in the world
- See the current temperature, feels-like, humidity and wind
- See a 7-day forecast
- Automatic light and dark mode

Weather data comes from [Open-Meteo](https://open-meteo.com/), a free, open-source weather API.

## Run locally

```bash
python -m http.server 8000
```

Then open http://localhost:8000.
